Rocrail server connection

Use the TCP control port (RCP, default 8051) – the same endpoint Rocview/OpenDecoder clients use.

Loco list & scroll (global)

This Accessory key

Controls or displays one track-diagram element of the Rocrail plan, independent of loco selection. Turnouts, signals and outputs/buttons flip on press; turntables step to the next track; sensors, blocks and tracks are status-only.

This OLED key (Throttle / Loco-control view)

Rocview throttle view modes: applies only while controlling a locomotive. Each OLED key may show functions, loco portrait, or speed/direction independently.

Loco images & function icons via HTTP

Rocview / Rocrail HTTP image service must expose files (Rocview Wiki: web service). Composites download from http://<TCP host above>:port/path/file.
